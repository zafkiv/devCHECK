# 🤖 Farcaster Monitor Bot

Telegram-бот для мониторинга новых кастов пользователей Farcaster.

## 📋 Возможности

- ✅ Добавление пользователей для мониторинга по FID
- ✅ Автоматическое отслеживание новых кастов
- ✅ Уведомления в Telegram группу
- ✅ Режим реального времени (30 секунд)

## 🛠 Установка

### Требования
- Python 3.10+
- Telegram Bot Token
- Neynar API Key
